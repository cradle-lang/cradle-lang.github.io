# Support and Feedback

The public website and documentation have a different feedback route from
support for a CRADLE software distribution.

## Website and documentation feedback

Use the official
[website repository issue tracker](https://github.com/cradle-lang/cradle-lang.github.io/issues)
to report a broken link, documentation problem, accessibility issue, or defect
in the browser Workbench.

Before opening an issue, search existing reports and remove confidential or
sensitive scenario information. The public issue tracker is not a licensing or
private operational-support channel.

## Distribution and licensing support

Support for a CRADLE distribution is available to authorized users through the
support channel associated with their license or organization.

## Before contacting support

Provide the following information where applicable:

- CRADLE version
- Host operating system
- Selected deployment target
- Scenario name
- Command executed
- Relevant error output
- Relevant logs with sensitive information removed

## Protect sensitive information

Do not send passwords, private keys, access tokens, credentials, or
confidential scenario data in a support request. Remove or redact sensitive
information from logs before sharing them.

## Contact the distribution team

Use the support or licensing contact supplied with your authorized CRADLE
distribution. This development documentation does not specify a separate public
support channel.
