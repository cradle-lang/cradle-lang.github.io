# Support

Support is available to authorized CRADLE users through the support channel
associated with their license or organization.

## Before contacting support

Provide the following information where applicable:

- CRADLE version
- Host operating system
- Selected deployment target
- Scenario name
- Command executed
- Relevant error output
- Relevant logs with sensitive information removed

## Protect sensitive information

Do not send passwords, private keys, access tokens, credentials, or
confidential scenario data in a support request. Remove or redact sensitive
information from logs before sharing them.

## Contact the CRADLE team

Use the support or licensing contact supplied with your authorized CRADLE
distribution. Public support contact details will be added when the product
support model has been approved.
