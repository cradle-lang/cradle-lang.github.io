# Install CradleXC

CradleXC provides the `cxc` command-line interface used to validate, compile and process CRADLE scenarios.

This guide covers installing CradleXC from source, verifying the installation and checking the dependencies available on your system.

## Install from source

At the `v0.18.1` release, the upstream repository identifies building from
source as the available CradleXC installation path. Install the CLI from the
upstream checkout:

```bash
git clone https://github.com/cradle-lang/cradle-v2.git
cd cradle-v2
cargo install --path crates/cradle-cli
```

The production build installs the `cxc` command. It does not include the
development-only `migrate`, `import`, `deploy`, `update`, `destroy` or
`extract` subcommands. A separate development build uses
`cargo install --path crates/cradle-cli --features dev` and is intended for
development workflows rather than production package installation.

## Verify the installation

Confirm that the `cxc` executable is available:

```bash
cxc --version
```

If the command succeeds, CradleXC is installed and available on your system `PATH`.

You can also confirm its location with:

```bash
which cxc
```

## Check dependencies

Run the built-in dependency check:

```bash
cxc doctor
```

`cxc doctor` checks the dependencies required by CradleXC and any backend plugins
currently available to it.

If dependencies are missing, display the installation guidance with:

```bash
cxc install-deps
```

:::important
Resolve any required dependency issues reported by `cxc doctor` before using the
affected functionality.
:::

## View the current configuration

To inspect the configuration currently used by CradleXC, run:

```bash
cxc config
```

This is useful when checking local paths, repository configuration or
other settings used by the CLI.

## Update CradleXC

Pull the upstream source and reinstall the CLI:

```bash
cd cradle-v2
git pull
cargo install --path crates/cradle-cli
```

Confirm the installed version:

```bash
cxc --version
```

## Troubleshooting

`cxc: command not found`

Confirm that CradleXC is installed:

```bash
which cxc
```

If no path is returned, verify the installation and ensure the location containing the
`cxc` binary is included in your system `PATH`.

## Missing dependencies

Run:

```bash
cxc doctor
```

Then view the corresponding installation guide:

```bash
cxc install-deps
```
