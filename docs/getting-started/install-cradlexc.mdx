# Install CradleXC

CradleXC provides the `cxc` command-line interface used to validate, compile, render, deploy, and inspect CRADLE scenarios.

This guide covers installing CradleXC, verifying the installation and checking the dependencies available on your system.

## Install from source

CradleXC 0.16.0 is installed from the upstream Cargo workspace.

From a checkout of the CradleXC source, install the `cxc` binary with Rust and
Cargo:

```bash
cargo install --path crates/cradle-cli
```

The release does not currently provide a prebuilt package. Backend plugins are
separate executables and are not included in the CradleXC install.

## Verify the installation

Confirm that the `cxc` executable is available:

```bash
cxc --version
```

If the command succeeds, CradleXC is installed and available on your system `PATH`.

You can also confirm its location with:

```bash
which cxc
```

## Check dependencies

Run the built-in dependency check:

```bash
cxc doctor
```

`cxc doctor` checks the dependencies required by CradleXC and any backend plugins
currently available to it.

If dependencies are missing, display the installation guidance with:

```bash
cxc install-deps
```

:::important
Resolve any required dependency issues reported by `cxc doctor` before using the
affected functionality.
:::

## View the current configuration

To inspect the configuration currently used by CradleXC, run:

```bash
cxc config
```

This is useful when checking local paths, repository configuration or
other settings used by the CLI.

## Update CradleXC

Pull the desired source revision and reinstall the binary:

```bash
cargo install --path crates/cradle-cli --force
```

Confirm the installed version with `cxc --version`.

## Troubleshooting

`cxc: command not found`

Confirm that CradleXC is installed:

```bash
which cxc
```

If no path is returned, verify the installation and ensure the location containing the
`cxc` binary is included in your system `PATH`.

## Missing dependencies

Run:

```bash
cxc doctor
```

Then view the corresponding installation guide:

```bash
cxc install-deps
```
