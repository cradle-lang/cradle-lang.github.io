# Import Existing Definitions

CradleXC can import a static Vagrant/Ansible deployment definition into a validated `.cradle` scenario.

```bash
cxc import \
  --from /path/to/deployment \
  --name ImportedLab \
  --output scenarios/ImportedLab.cradle
```

The importer reads a static `Vagrantfile`, inventory, and top-level YAML playbooks. Dynamic Ruby, Ansible roles, includes, and arbitrary module behavior cannot be reconstructed reliably; review all warnings and the generated source before using it.

Validate the result immediately:

```bash
cxc validate -i scenarios/ImportedLab.cradle
```

Run `cxc import --help` for the exact interface in your installed release.
