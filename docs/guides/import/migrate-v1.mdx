# Migrate from v1

Use `cxc migrate` to convert a v1 scenario to v2 syntax.

```text
v1 .cradle → cxc migrate → v2 .cradle → cxc validate
```

```bash
cxc migrate -i reference/v1-scenarios/HelloWorld.cradle -o scenarios/HelloWorld-v2.cradle
cxc validate -i scenarios/HelloWorld-v2.cradle
```

The migration updates v1 conventions such as quoted booleans and numbers, numeric event identifiers, and `waitfor()` dependencies. Review the generated file, especially artifact locations, role variables, event ordering, and any warnings from validation.

For new scenarios, use the v2 language directly: typed literals, semantic event names, structured key-value blocks, `dependsOn()`, and `include` statements.
