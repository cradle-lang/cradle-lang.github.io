# Forensic Data

CradleXC separates scenario authoring from the storage locations used for forensic resources and extracted datasets.

```toml
forensic_dir = "/srv/cradle/forensic"
dataset_dir = "/srv/cradle/datasets"
```

`forensic_dir` identifies host-side forensic resources. `dataset_dir` is the default destination for extracted data when no output directory is supplied.

## Collect data

Forensic-data collection is provided by the selected backend and its target
environment rather than by a CradleXC command. Follow the backend's
documentation for its supported collection workflow and output layout.

Confirm the backend's prerequisites with `cxc doctor` before using its own
collection tooling.

## Generate artifacts

Artifact generation is backend-specific. Use the artifact tooling documented by
the selected backend, and keep generated files outside the scenario source tree
when they contain environment-specific or sensitive data.
