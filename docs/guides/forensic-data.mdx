# Forensic Data

CradleXC separates scenario authoring and target-file generation from forensic
data collection. The `cxc extract` command runs forensic extraction against a
deployment directory and stores the result in the configured dataset directory
unless an output directory is supplied.

## Collect data

After a deployment has produced its hosts file, extract data with:

```bash
cxc extract \
  --scenario HelloWorld \
  --deploy-dir ./output/HelloWorld
```

Use `--output <directory>` to override the configured forensic-data output
location. Extraction depends on the forensic tools and deployed environment;
it does not deploy infrastructure or run scenario events.

Confirm the backend's prerequisites with `cxc doctor` before using its own
collection tooling.

## Generate artifacts

Artifact generation is backend-specific. Use the artifact tooling documented by
the selected backend, and keep generated files outside the scenario source tree
when they contain environment-specific or sensitive data.
