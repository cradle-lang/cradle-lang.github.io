# Abstract Syntax Tree

The AST records the parsed CRADLE document: metadata, instances, networks, objects, and event declarations. It preserves the source-level structure before semantic resolution.

`cxc parse -i <scenario.cradle>` displays the parsed AST as JSON. Use it when diagnosing parsing behavior; use `cxc check` for parse-and-validation diagnostics.

The AST is an implementation representation, not a stable integration contract.
