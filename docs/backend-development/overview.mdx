# Backend Development

A CradleXC backend is an out-of-process executable that consumes Deployment IR and renders target-specific files. It can be implemented in any language and is discovered as `cxc-backend-<name>`.

The backend boundary keeps provider-specific choices outside the CRADLE language and the compiler. Start with [Plugin Model](./plugin-model), then consult the protocol before implementing a backend.
