## Related cybersecurity frameworks

CRADLE scenarios can use semantic tags from established cybersecurity
frameworks and catalogs.

- [MITRE ATT&CK](https://attack.mitre.org/) — tactics, techniques, and procedures
- [MITRE D3FEND](https://d3fend.mitre.org/) — defensive cybersecurity techniques

## Reproducibility record

When documenting a CRADLE experiment, preserve the scenario file alongside
the product and provider versions. This record helps other authorized users
understand the conditions under which the environment was generated and run.
