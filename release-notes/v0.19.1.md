# Announcing CradleXC 0.19.1

<!-- markdownlint-disable-next-line MD036 -->
*22 September 2026*

CradleXC 0.19.1 is a focused maintenance release for scenarios that use
Git-backed configuration content. Routing configurations now follow the same
content-fetching path as every other referenced configuration.

This makes remote configuration repositories more predictable for scenarios
that use `linux-routing` or `win-routing`, while preserving the existing
`cxc` workflow and configuration model.

## Highlights

* Fetch `linux-routing` and `win-routing` configurations from Git-backed content repositories like other configurations.
* Keep routing configuration resolution consistent with local and remote content sources.
* Upgrade the CradleXC package to version 0.19.1.

## Fixed

### Git-backed routing configurations

When a scenario references `linux-routing` or `win-routing` and its
`config_dir` is a Git URL, CradleXC now attempts to fetch the referenced
configuration through the normal configuration-content path. These routing
configurations are no longer excluded from on-demand retrieval.

This change affects content resolution only. The scenario still needs the
corresponding routing configuration in the configured repository, and the
backend remains responsible for rendering the generated target-specific files.

## Installation and upgrade

Upgrade the CradleXC package through the CRADLE APT repository:

```bash
sudo apt update
sudo apt install cxc
```

Confirm the installed version and local environment:

```bash
cxc --version
cxc doctor
```

Existing `config_dir` settings continue to work. No configuration migration is
required; Git-backed repositories that provide the referenced routing
configuration can now be resolved through the same path as other configs.
