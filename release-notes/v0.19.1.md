# Announcing CradleXC 0.19.1

<!-- markdownlint-disable-next-line MD036 -->
*22 September 2026*

CradleXC 0.19.1 is a focused maintenance release for users who build
deployment files from content repositories. It corrects how the compiler
resolves the routing configurations used by scenarios, so those configurations
are fetched consistently with other referenced configuration content.

The release keeps the existing `cxc` workflow and command surface intact while
making Git-backed content resolution more complete. Projects that use
`linux-routing` or `win-routing` can now rely on the same on-demand
configuration lookup behavior as other configs.

## Highlights

* Fetch `linux-routing` and `win-routing` configurations from configured
  content repositories like any other referenced configuration.
* Preserve the existing `cxc build` and `cxc rebuild` interfaces and content
  directory settings.
* Upgrade the CradleXC package version to 0.19.1.

## Fixed

### Routing configuration resolution

When `config_dir` or an equivalent CLI content source points to a Git
repository, `cxc` now attempts to fetch `linux-routing` and `win-routing`
when a scenario references them and the content is not already materialized.
Previously, these names were excluded from the generic fetch path even though
they are resolved as configuration content during the build workflow.

Local configuration directories and already materialized routing templates are
unchanged. As with other referenced content, a repository that does not
contain the requested configuration does not itself make a build succeed; the
normal configuration validation and rendering errors remain authoritative.

## Installation and upgrade

Install or upgrade the CradleXC package through the CRADLE APT repository:

```bash
sudo apt update
sudo apt install cxc
```

After upgrading, verify the version and local environment:

```bash
cxc --version
cxc doctor
```

No command-line migration is required. Existing `config_dir`,
`--config-dir`, and Git-backed content workflows continue to use their
previous syntax.
