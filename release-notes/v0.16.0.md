# Announcing CradleXC 0.16.0

<!-- markdownlint-disable-next-line MD036 -->
*24 August 2026*

CradleXC 0.16.0 is a maintenance release for the CRADLE cross compiler. It
updates the version and package metadata for the compiler workspace without
changing how CRADLE scenarios are written, validated, compiled, rendered or
deployed.

This release is intended for users and packagers who need the current
CradleXC version identifier. Existing scenarios and workflows continue to use
the same `cxc` commands and external backend plugin model.

## Highlights

* Updates the CradleXC workspace and in-tree crate versions to `0.16.0`.
* Keeps the existing CRADLE language, compiler pipeline and `cxc` CLI behavior
  unchanged.
* Continues to distribute deployment backends as external
  `cxc-backend-<name>` plugins rather than compiling them into `cxc`.

## Changed

### Package and version metadata

The workspace package version is now `0.16.0`, and the in-tree CradleXC crates
use the same version. Distribution metadata uses the consistent description
“Cyber-testbed Reconstruction and Automation Description Language (CRADLE)
Cross Compiler.”

This is a packaging change rather than a compiler or language change. No
scenario migration is required, and no command-line flags, output formats or
backend invocation contracts changed in this release.

### Core CLI distribution

CradleXC remains a standalone core CLI whose executable is named `cxc`.
Deployment targets are not built into the core binary: `cxc deploy` and
`cxc emit` use discoverable `cxc-backend-<name>` plugins, while
backend-independent commands such as validation and compilation remain
available without a deployment plugin.

Generated deployment files and backend-managed infrastructure remain separate
concerns. Rendering or compiling a scenario does not automatically deploy it.

## Installation and upgrade

No prebuilt `cxc-core` package is published for this release. Build CradleXC
from the source checkout with Rust and Cargo:

```bash
cargo install --path crates/cradle-cli
```

Verify the installed CLI with:

```bash
cxc --version
cxc doctor
```

Users upgrading from an earlier CradleXC release can rebuild or reinstall the
same way. Existing `.cradle` scenarios do not require changes for this
metadata-only release. Install any deployment backend separately and make its
`cxc-backend-<name>` executable discoverable on `PATH` before using
target-specific rendering or deployment commands.

## Known limitations

The release does not add a Docker or cloud deployment backend, asynchronous
event execution, or a web UI. Live deployment and forensic extraction still
require the relevant external backend and a VM-capable environment.
