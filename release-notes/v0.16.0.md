# Announcing CradleXC 0.16.0

<!-- markdownlint-disable-next-line MD036 -->
*24 August 2026*

CradleXC 0.16.0 is a maintenance release for the CRADLE cross-compiler
toolchain. It updates the release metadata used by the workspace crates and
distributions without changing the `cxc` command set or scenario-processing
workflow.

This release benefits users and package maintainers who identify CradleXC
through package metadata. Debian and RPM listings now present the same concise
description, making the package identity clearer while preserving the existing
source installation path and runtime behavior.

## Highlights

* Updates all workspace crates to version 0.16.0.
* Aligns Debian and RPM package descriptions around the CRADLE Cross Compiler.
* Preserves the existing `cxc` commands, dependencies and source-build workflow.

## Changed

### Consistent package identity

The workspace package description is now:

```text
Cyber-testbed Reconstruction and Automation Description Language (CRADLE) Cross Compiler
```

The Debian package no longer carries a separate extended description, and the
RPM summary uses the workspace description. As a result, the two package
formats expose the same single-line description.

### Workspace version

The workspace and its CradleXC crates are versioned as 0.16.0. This is package
and release metadata only; the release does not add or remove `cxc` commands or
change the CRADLE scenario workflow.

## Installation and upgrade

At this tag, the upstream project documents installation from source. From a
checkout of CradleXC 0.16.0, install the CLI with:

```bash
cargo install --path crates/cradle-cli
```

The installed executable is `cxc`. Existing source-based installations can be
rebuilt from the 0.16.0 checkout to receive the updated version metadata.
Backend capabilities and runtime dependencies remain determined by the
installed backend plugins and the local environment.

## Known limitations

This release does not introduce a new prebuilt package distribution or change
the behavior of scenario validation, compilation, backend generation,
deployment, event execution or forensic extraction. No migration is required
for existing CRADLE scenarios.
