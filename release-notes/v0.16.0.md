# Announcing CradleXC 0.16.0

<!-- markdownlint-disable-next-line MD036 -->
*24 August 2026*

CradleXC 0.16.0 is a packaging and release-metadata update for the CRADLE
cross-compiler and `cxc` command-line interface.

The release keeps the compiler workflow unchanged while making the package
identity consistent across supported Linux package formats. This gives
operators and package indexes a clear, stable description of the tool they are
installing.

## Highlights

* Updates the CradleXC package version to 0.16.0.
* Uses one CRADLE cross-compiler description for Debian and RPM package metadata.
* Retains the existing `cxc` CLI and external backend workflow.

## Changed

### Consistent package description

The workspace and CLI package now use this description:

```text
Cyber-testbed Reconstruction and Automation Description Language (CRADLE) Cross Compiler
```

Debian and RPM metadata use the same single-line text. The Debian package no
longer carries a separate extended description, so package listings identify
the same product regardless of package format.

### CLI behavior remains unchanged

This release does not add or remove compiler commands, backend protocols or
runtime dependencies. Existing scenario validation, compilation, deployment,
backend plugin discovery and environment checks continue to use the interfaces
provided by the tagged `cxc` binary.

## Installation and upgrade

CradleXC 0.16.0 can be built from the tagged source checkout:

```bash
cargo install --path crates/cradle-cli
```

Verify the installed CLI version:

```bash
cxc --version
```

The package metadata change does not imply that generated files are deployed
or that external backend plugins are installed automatically.

## Known limitations

Backend capabilities and dependency checks remain plugin-dependent. Install
and configure any required `cxc-backend-<name>` plugin separately before using
target-specific workflows.
