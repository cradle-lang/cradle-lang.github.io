CRADLE documentation
====================

This repository contains the user and developer documentation for CRADLE,
built with Sphinx and the Furo theme.

Local preview
-------------

Create a virtual environment, install ``docs/requirements.txt``, then run::

   make -C docs html

Open ``docs/build/html/index.html`` in a browser. For writing conventions and
the navigation checklist, see ``docs/source/contributing.md``.
