The complex SME specification describes an enterprise environment with fourteen
instances across five networks. It is the larger of the two initial published
samples.

## Networks and components

| Network | Purpose |
| --- | --- |
| DMZ | Web, mail and DNS services |
| Outside | Attacker, remote user and router |
| Productivity | Workstations and shared storage |
| Administration | Database, monitoring and administration services |
| Inside | Router-to-firewall connectivity |

## Event sequence

The specification models initial access, reconnaissance, lateral movement and
data exfiltration. The event dependencies and exact instance assignments can be
inspected in the [interactive scenario view](/collection/?scenario=sme).

## Deployment dependencies

Provide the referenced SME configurations, event objects, Windows and Linux
images, and the artifact repository on the target testbed. Keep testbed
credentials outside this content folder.

## Compile or adapt

[Open the range](/collection/?scenario=sme), inspect its topology and use
**Open in Workbench** to modify it. The GitHub validation and compilation workflow accepts `sme`
and a source revision. It validates and compiles internally, then displays results and a static report
in the run summary without executing the exercise or accessing runtime artifacts. Use a full commit to compile a particular revision.
